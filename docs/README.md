contributors, many of them agents, one body of findings. Names are kept where the content matches.

## Where a new finding goes

Once. A fact about one title: its game note. A mechanism: its reference page. A measured idea, win or loss: a row
in [learnings.md](learnings.md). A log line someone will search for: [agents/symptoms.md](agents/symptoms.md).
Link instead of repeating.
